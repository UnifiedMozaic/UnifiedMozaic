# ロゴ

M の下に U を積んだ白黒の印（猫の顔にも見えるのは意図したもの）。色は白と黒の 2 色だけで使う。

| ファイル | 中身 |
|---|---|
| `logo-black.svg` / `logo-white.svg` | 印だけ（背景は透明）。明るい背景には黒、暗い背景には白 |
| `logo-black-on-white.png` / `logo-white-on-black.png` | 印に背景色をつけたもの（1024×1024） |
| `icon.svg` / `icon-1024.png` | 黒い角丸の板に白抜きの印（アバターやアプリのアイコン用） |
| `social-preview.png` | GitHub のプレビュー画像（1280×640） |

VSCode 拡張のアイコン（`editors/vscode/icons/`）も同じ形。
